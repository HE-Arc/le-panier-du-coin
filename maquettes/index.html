Documentation de maquette

Sommaire des 14 maquettes

HTML statique + Tailwind CDN, aucun outil de build : un clic sur un fichier suffit pour l'ouvrir dans un navigateur. Le design system commun vit dans assets/theme.js (couleurs, polices, ombres) et assets/style.css (polices Google, focus, bandeau « maquette »). Chaque page partage le même header, le même footer et les mêmes composants (cartes annonce, boutons, badges).
